# Загрузка производства — Android APK

Проект Android-приложения (WebView) на базе `monitoring.html` с полноценной загрузкой данных с вашего локального сервера (`/api/files` и `/api/scan-directory`).

## Как работает подключение к серверу

- При первом запуске приложение запрашивает адрес вашего сервера (например, `http://192.168.1.10:5000`) и сохраняет его в памяти телефона.
- Страница `index.html` загружается через `WebView.loadDataWithBaseURL(serverUrl, ...)`, поэтому все запросы `/api/files` и `/api/scan-directory` идут напрямую на сервер **в режиме same-origin (без CORS-блокировок)** — даже если на сервере не настроены заголовки CORS.
- Поменять адрес сервера можно в любой момент кнопкой **«Сервер»** на главной панели или в окне **«Настройки»**.

## Сборка APK через GitHub Actions

1. Создайте новый репозиторий на GitHub (например, `monitoring-apk`).
2. Распакуйте архив и загрузите все файлы в корень репозитория.
3. Если папка `.github` не загрузилась при перетаскивании — откройте вкладку **Actions** → **set up a workflow yourself** и вставьте содержимое `.github/workflows/build-apk.yml`.
4. Дождитесь зелёной галочки (~2 минуты) и скачайте **`Production-Monitoring-APK`** из блока **Artifacts**.
