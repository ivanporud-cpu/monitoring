Настройки

Подключение и кэш
Сервер находится автоматически; кнопкой «Сервер» можно запустить поиск в сети или ввести адрес вручную.
Когда локальный сервер недоступен, приложение автоматически подгружает смены и чертежи с Яндекс Диска.
Даты старше 3 дней берутся из кэша; последние 3 дня и все будущие даты пересчитываются всегда.
Принудительно очищает кэш и заново пересчитывает все даты с сервера (настройки линий не сбрасываются).
Отображение
Тёмное оформление экрана. Также переключается кнопкой в шапке.
По умолчанию выключено, чтобы сразу видеть карточки смен.
%
Масштаб всей страницы (50–200%). Шаг 1%.
Линии и уведомления
По умолчанию выключено — переключать линии можно свайпом влево и вправо.
Минимум 5 секунд. Работает только при включённом автопереключении.
Фоновая проверка выбранных линий (приходит одно общее уведомление на телефон).

Настройка линий и папок

По умолчанию папки находятся сами (Мурат Стандарт, Мурат Нестандарт, Ламинация). При необходимости измените название, выберите другую папку или задайте шаблон с {YEAR}, {MONTH}, {MONTH_NUM}.
