Названия линий

Линия без названия пропускается при переключении и сканировании.

Шаблоны путей (с макросами)

Доступные макросы: {YEAR} — текущий год, {MONTH} — месяц (январь...декабрь), {MONTH_NUM} — номер месяца (01-12).
Если шаблон задан, он используется вместо выбранной папки. Оставьте пустым для использования фиксированного пути.
Макрос {MONTH} необязателен: можно указать папку линии без месяца (напр. \\Сервер\Общая\{YEAR}\Мурат Стандарт) — папки месяцев определяются автоматически.
